# Experimental Laya advisory; deterministic trading

The final BUY/SELL/NO_TRADE decision, minimum score, selected-asset options gate, risk/sizing, execution ownership, and protective TP/SL are deterministic. Laya is **not a judge or confirmation**: `_print_decision_audit` requests a separate asynchronous commentary at `FINAL_GATE` only. No advice is copied to final decision, consensus, order payload, or protective exit. An absent, late, invalid, wrong-symbol or stale response has a distinct status, never approval. One daemon worker is allowed at a time (3-second deadline); a hung worker prevents further launches until it finishes. Results are consumed once for an exact snapshot+symbol+decision, only within a five-second TTL. No blocking inference on trade path.

Laya is **off by default**: set `JARVIS_LAYA_ADVISORY=true` explicitly to attempt optional commentary. Install the actual `NandhaKishorM/laya` package and its compatible pretrained checkpoint separately under operator control; this PR does not install or download a checkpoint and does not verify inference or market fitness. Upstream API verified from source: `Router.predict(state, questions)` gives `answers[question_id].choice` (and confidence). General-purpose choice confidence is not a calibrated trading probability. No invented market-specific model or fine-tuning is claimed.

The retired Ollama surface (`ollama_integration`, Parts 1–12 model hooks, cortex, option whale/part validators, specialist pool, market oracle, model hedge advisor, cognitive error diagnosis, HUD chat, launcher, Gemini's Ollama fallback, diagnostic probes, standalone RAG) cannot call the Ollama server. Compatibility functions return explicit unavailable/no-vote values. The previous DeepSeek entry veto has no reachable caller and returns nonapproval if called; the deterministic minimum-score override was removed, and low scores are NO_TRADE. Model strategy/hedge votes cannot set sizing, strike, execution, or exits even if `JARVIS_PURE_ALGO=false`. The BTC Oracle now requires real spot/options PCR/max pain/orderbook imbalance, otherwise WAIT; its execution gate rejects nonlocal and >10-minute-old forecasts even in soft-gate mode. Its existing deterministic market heuristics are *not* validated as profitable or equivalent to the retired DeepSeek veto. Do not deploy until reviewed.

Safe offline checks: compile changed Python files; `python -m unittest -v test_jarvis_laya_advisor test_jarvis_laya_runtime tests.test_options_math_integration tests.test_pure_options tests.test_laya_migration_integration tests.test_audit_regressions`. The options tests extract production methods via AST, **not full main-module imports**. Integration tests exercise actual lightweight production modules with network mocked (cortex, hedge paper path without background monitor, oracle, OracleTradeGate, specialist pool), and adapter fake Router. Heavy numpy/pandas/websockets and actual Laya checkpoint are not available in the offline sandbox; full `JarvisElite`/12-part live graph, exchange connectivity, fill/close behavior, and real inference are untested. No model downloads, exchange requests, live orders, merge, or deployment were performed.

The standalone Gemini Supreme advisor and Doctor Gemini diagnosis now return unavailable/neutral values even with API keys; they cannot issue model requests or change trading thresholds, leverage or overrides. The opt-in `kie_gpt6_client` remains an independent external text client (`JARVIS_ENABLE_EXTERNAL_AI=1` plus API key); it is not wired into this trading decision graph and has **not** been replaced by Laya. This PR must not be described as retiring every optional external AI service.

`run_all_parts.py` no longer starts the legacy AI chain, distributed AI HUD service, predictor or predictive strategy/size pipeline. Its execution signal is copied only from the core `trade_signal` with real positive finite entry/TP/SL and current price; missing data stays `NO_TRADE` rather than synthetic SELL/price/candles. Neural sklearn/torch inference in Part 2 and the core is retired, including backtest auto-training, while Part 5's observed OHLCV statistical features remain. There is no assertion that removing a model veto is equivalent to a validated deterministic policy; explicit legacy non-pure live mode remains fail-closed.

Static audit parsed 73 non-test Python source files (of 123 fetched repository paths), classified remaining `predict`, model SDK and HTTP calls by reachability, and found no active Ollama HTTP call path. Residual legacy model code may still appear syntactically after unconditional unavailable returns; do not equate this source audit with running the whole system. New offline tests cover actual lightweight Doctor/Gemini/runner import behavior and AST-isolated heavy Part 2/core methods; the coordinator source contract is a static assertion, **not a full live coordinator test**. No checkpoint is installed or inference observed.
